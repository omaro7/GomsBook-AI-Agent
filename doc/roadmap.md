# GomsBook AI Agent Roadmap

> Development roadmap for building an AI-powered EPUB3 authoring and publishing platform.

---

# Vision

GomsBook AI Agent aims to become an intelligent publishing assistant that automates EPUB authoring, accessibility validation, document analysis, and publishing workflows through AI Agents.
